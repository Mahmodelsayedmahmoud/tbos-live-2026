## 🎯 نظرة عامة

TBOS هو نظام تشغيلي متكامل مصمم لإدارة العمليات التجارية والنقل بكفاءة عالية. يوفر النظام حلاً شاملاً لإدارة:

- 📦 **الوارد**: تتبع الكونتينرات والبضائع الواردة
- 🚚 **المندوبون**: إدارة المندوبين والرحلات
- 🔄 **سير العمل**: تتبع مراحل العمليات
- 💵 **الكاشير**: إدارة المدفوعات
- 📊 **التقارير**: تحليلات وإحصائيات شاملة
- 🎯 **لوحة العمليات**: رؤية شاملة وموحدة

## 🚀 البدء السريع

### 1. تثبيت التبعيات
```bash
npm install
```

### 2. إعداد قاعدة البيانات

#### الخطوة 1: فتح Supabase Dashboard
```
https://supabase.com/dashboard/project/jkzgpfjaovqxxtrkxalu
```

#### الخطوة 2: تنفيذ مخطط قاعدة البيانات
1. اذهب إلى **SQL Editor**
2. انقر على **New Query**
3. انسخ محتوى ملف `setup-database.sql`
4. الصقه في المحرر
5. انقر على **Run**

#### الخطوة 3: تفعيل Realtime
1. اذهب إلى **Database** → **Replication**
2. فعّل Realtime على جميع الجداول

### 3. تشغيل التطبيق
```bash
npm run dev
```

### 4. فتح المتصفح
```
http://localhost:5173
```

### 5. تسجيل الدخول
```
admin / admin123
```

## 🔄 دورة العمل

```
ENTRY (الوصول)
  ↓
DOCK (الرصيف)
  ↓
PREPARATION (التحضير)
  ↓
INVENTORY (الجرد)
  ↓
LOADING (التحميل)
  ↓
DECISION ENGINE (محرك القرارات)
  ↓
├─ GO_TO_CASHIER → CASHIER → COMPLETED
└─ WAIT_CASHIER → QUEUE → (انتظار) → CASHIER → COMPLETED
```

---

## 🎯 محرك القرارات

يتخذ النظام قرارات ذكية تلقائياً:

### 🟢 GO_TO_CASHIER
- الجرد مكتمل
- التحميل مكتمل
- الفرع نشط
- يوجد سعة في الكاشير

### 🟠 WAIT_CASHIER
- الكاشير ممتلئ
- يتم إضافة المندوب للطابور

### 🔴 BLOCKED_INVENTORY
- الجرد غير مكتمل

### 🟠 WAIT_LOADING
- التحميل غير جاهز

### 🟠 WAIT_CONGESTION
- ازدحام تشغيلي

## 🔧 التقنيات المستخدمة

### Frontend
- **React 18** - مكتبة الواجهة

- **Vite 6** - أداة البناء
- **Tailwind CSS 4** - تنسيق CSS
- **React Router 6** - التوجيه
- **Lucide React** - الأيقونات

### Backend
- **Supabase** - قاعدة بيانات سحابية
- **PostgreSQL** - قاعدة البيانات
- **Real-time WebSockets** - التحديث اللحظي
- **Auto-reconnect** - إعادة الاتصال التلقائي
- **JWT Authentication** - نظام المصادقة

### Libraries
- **@supabase/supabase-js** - عميل Supabase
- **xlsx** - قراءة/كتابة Excel

3. تحقق من RLS policies
4. جرب اختبار الاتصال

### المزامنة لا تعمل
1. تأكد من تفعيل Realtime في Supabase
2. تحقق من حالة الاتصال
3. أعد الاتصال يدوياً إذا لزم الأمر

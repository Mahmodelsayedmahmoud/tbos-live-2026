## 🚀 البدء السريع

### 1. تثبيت التبعيات
```bash
npm install
```

### 2. تشغيل التطبيق
```bash
npm run dev
```

### 3. فتح المتصفح
```
http://localhost:5173
```

### 4. إعداد قاعدة البيانات
- افتح `http://localhost:5173/#/setup-db`
- أو انقر على "إعداد قاعدة البيانات" في صفحة تسجيل الدخول
- نفّذ `setup-database.sql` في Supabase SQL Editor

### 5. تسجيل الدخول
```
admin / admin123
```

## 🔄 ميزة إعادة الاتصال التلقائي

### كيف تعمل؟

```
1. الاتصال يعمل بشكل طبيعي ✅
   ↓
2. انقطاع الـ Transport (فقدان الإنترنت، خطأ في الخادم)
   ↓
3. اكتشاف الخطأ تلقائياً ❌
   ↓
4. تغيير الحالة إلى "disconnected"
   ↓
5. بدء إعادة الاتصال التلقائي 🔄
   ↓
6. محاولة 1: الانتظار 1 ثانية
   ↓
7. محاولة 2: الانتظار 2 ثانية
   ↓
8. محاولة 3: الانتظار 4 ثانية
   ↓
9. ... (زيادة تدريجية حتى 30 ثانية)
   ↓
10. نجاح إعادة الاتصال ✅
    ↓
11. إعادة إنشاء جميع القنوات
    ↓
12. استئناف المزامنة اللحظية 🔄
```

### حالات الاتصال

#### ✅ متصل (Connected)
- نقطة خضراء مع تأثير ping
- أيقونة Cloud خضراء
- نص "متصل"

#### 🔄 جاري إعادة الاتصال (Reconnecting)
- نقطة صفراء متحركة
- أيقونة RefreshCw تدور
- نص "جاري إعادة الاتصال..."

#### ❌ غير متصل (Disconnected)
- نقطة حمراء
- أيقونة CloudOff حمراء
- نص "غير متصل"
- زر إعادة الاتصال اليدوي

## 🐛 حل المشاكل

### المشكلة: تداخل العناصر

**الحل:**
1. تأكد من أن `src/index.css` يحتوي على CSS كامل
2. تحقق من أن Layout يستخدم `.app-container`
3. تأكد من أن Sidebar يستخدم `.sidebar`
4. تحقق من أن Header يستخدم `.app-header`

### المشكلة: انقطاع الاتصال

**الحل:**
1. انتظر إعادة الاتصال التلقائي
2. أو انقر على زر إعادة الاتصال اليدوي 🔄
3. تحقق من اتصال الإنترنت
4. أعد تحميل الصفحة إذا لزم الأمر

### المشكلة: لا تظهر البيانات

**الحل:**
1. تأكد من تنفيذ `setup-database.sql`
2. تحقق من Console للأخطاء
3. أعد تحميل الصفحة

### المشكلة: المزامنة لا تعمل

**الحل:**
1. تأكد من تفعيل Realtime في Supabase
2. تحقق من حالة الاتصال
3. أعد الاتصال يدوياً إذا لزم الأمر
